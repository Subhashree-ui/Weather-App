# Weather App

A weather app built with **vanilla JavaScript**, HTML, and CSS. Enter any city name and get its current temperature and wind speed, fetched live from the OpenWeatherMap API.

## 🔗 Live Demo
[Click here to try it out](https://subhashree-ui.github.io/Weather-App/weather.html)

## ✨ Features
- Search weather by city name
- Shows live temperature (°C) and wind speed
- Alert when the input is empty
- Error message for invalid city names (the app doesn't crash)

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeatherMap API

## 📚 Concepts Practiced
- Fetching data from an API using `fetch()` and `.then()`
- Working with JSON data and nested objects
- Template literals for building dynamic URLs
- DOM manipulation and event listeners
- Handling errors and invalid input

## 🚀 How to Run
1. Clone or download this repository
2. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
3. Add your key in the `apiKey` variable in `weather.html`
4. Open `weather.html` in a browser

## 📖 What I Learned
This project taught me how apps get live data from the internet. I learned how an API request works, how to read the response, and how to handle the case when a city isn't found. I also learned why API keys should be kept private.
